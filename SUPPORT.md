# Getting Help

Thanks for using EasyTV! Here is where to go for what.

| I want to… | Go to |
| --- | --- |
| Ask a question, share what I built, discuss ideas | [GitHub Discussions](https://github.com/orgs/easytv-ai/discussions) |
| Report a bug | [Open a bug report](https://github.com/easytv-ai/easytv-api/issues/new?template=bug_report.yml) |
| Request a feature | [Open a feature request](https://github.com/easytv-ai/easytv-api/issues/new?template=feature_request.yml) |
| Report a security vulnerability | [SECURITY.md](SECURITY.md) — never a public issue |
| Read the docs | [README](README.md) · [简体中文](README.zh-CN.md) · [website](https://easytv.ai) |
| Try it without installing | [easytv.ai](https://www.easytv.ai) |

Before asking, please search existing issues and discussions. When reporting a
problem, include the commit or version you run, how you deployed it, and logs
with secrets removed.

中文用户：Issue 与 Discussions 都可以直接用中文。
